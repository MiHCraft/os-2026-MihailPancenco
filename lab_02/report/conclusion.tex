\chapter*{Conclusions}

In this laboratory work, I studied the concepts of actors, use cases, notes, packages, and relationships in UML. Through the creation of ten use-case diagrams, I modeled the main functionalities of the Operating System, including authentication, file management, application execution, system configuration, monitoring, secure data management, and interactions with peripheral and network devices.

The diagrams provided a clear visual representation of how different actors interact with the system, highlighting the responsibilities of administrators, users, application programs, and external devices. By analyzing these interactions, I was able to understand the system boundaries, the flow of operations, and how supporting services like logging and permission checking ensure security and accountability.

Overall, studying and modeling these use cases helped me reinforce my understanding of UML principles, system analysis, and the role of the Operating System in managing resources, processes, and secure data. This report demonstrates the practical application of UML to real-world systems and provides me with a foundation for more advanced modeling tasks in future projects.
