# Operating Systems Laboratories

Laboratory work by Mihail Pancenco, FAF-243, Technical University of Moldova, 2026–2027.

Each laboratory contains three directories:

- `requirements/` — laboratory instructions.
- `submission/` — source code and required deliverables.
- `report/` — LaTeX sources and compiled PDF report.
