\chapter{Conclusions}

The experiments show why names, inodes and open descriptors must be treated separately. A hard link preserves access after another name is removed, a symbolic link can dangle, and an open descriptor can retain an unlinked file. Permissions distinguish file access from directory search, while sparse files distinguish apparent size from allocation. The measured disk, memory and CPU values describe Ubuntu running in VirtualBox: an ext4 root on /dev/sda2, six visible logical CPUs and about 5.11 GiB of RAM.
